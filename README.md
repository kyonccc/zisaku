# kataware — 左右無線・トラックボール付き分割キーボード（ZMK 設定）

自作の分割キーボード「kataware」用の ZMK ファームウェア設定です。
基板がまだない段階から使えるように、**「この通りに配線すればこのファームがそのまま動く」**という形で作ってあります。

> この一式は 2026年10月時点の ZMK `main` で、左手・右手・リセット用の
> 3つのファームウェアがビルドできることを確認済みです。
> 実物での動作（キー入力・トラックボール）は基板ができてから確認が必要です。

---

## 1. 全体の流れ

自作キーボードは大きく **ハードウェア** と **ファームウェア** の2つに分かれます。

```
[1] 仕様を決める  ← 今ここ（このリポジトリで決めた内容）
[2] 回路図・基板設計（KiCad など）   ← 下の「配線表」に合わせて設計
[3] ケース設計（3Dプリント/アクリル）
[4] 基板・部品の発注、はんだ付け
[5] ファームウェアのビルド・書き込み  ← このリポジトリがそのまま使える
[6] キーマップの調整
```

ファームウェアは「どのピンに何がつながっているか」が決まればほぼ完成します。
**このリポジトリのピン配置に合わせて基板を設計すれば、[5] はすぐ終わります。**

## 2. 想定している仕様

| 項目 | 内容 |
| --- | --- |
| 配列 | 片手 3行 × 6列 ＋ 親指 3キー ＝ 21キー（左右合計 42キー） |
| 接続 | 左右とも完全無線（Bluetooth）。PC とは右手側がつながる |
| マイコン | ProMicro nRF52840 互換（nice!nano v2 など） × 2 |
| トラックボール | 右手側。センサー PMW3610、ボール 25mm 推奨 |
| 電源 | リチウムポリマー電池（左右に1個ずつ） |

### なぜこの部品なのか

- **ProMicro nRF52840 互換（nice!nano v2 など）**
  - Bluetooth 内蔵・電池充電回路内蔵で、ZMK で最も実績がある
  - 使えるピンが多く（約18本）、キーマトリックス＋トラックボールを配線しても余裕がある
  - もっと小さい **Seeed XIAO nRF52840** もありますが、ピンが11本しかなく、
    キー21個＋トラックボールだとピンが足りません（シフトレジスタ等の追加回路が必要）。
    初めての1台目なら ProMicro 型がおすすめです。
- **PMW3610 センサー**
  - 低消費電力で、無線トラックボールの自作でよく使われる定番
  - 単体ではなく「PMW3610 ブレイクアウト基板（センサー＋レンズ付きの小基板）」を買うと簡単です
- **ボールは 25mm 推奨**
  - 34mm（moNa2 などの大きいもの）より小さく、持ち運び向き
  - 25mm 用のボールケース・支持球（ベアリング/セラミックボール）の作例が多い
  - 19mm も可能ですが、作例・部品が少なく、ケース設計の難易度が上がります
- **トラックボールを右手（PCとつながる側＝セントラル）に置く理由**
  - センサーのデータを左右間の無線で中継しなくてよいので、遅延が少なく設定も簡単
  - デメリット：右手側の電池の減りが早くなる（右だけ容量の大きい電池にすると◎）

### 「オーソリニア」か「カラムスタッガード」か

ファームウェア上は**どちらでも同じ**です（配線のつながり方が同じなら、キーの見た目の位置は関係ありません）。
キーの見た目の位置を変えたい場合だけ `boards/shields/kataware/kataware-layout.dtsi` の数字を変えます。

## 3. 配線表（基板設計のときに使う一番大事な表）

ピン名の `D4` などは ProMicro の端子名（D番号）です。

### キーマトリックス（左右共通）

ダイオードの向き：**列(COL) → 行(ROW)**（`col2row`）
つまり、各スイッチの後ろにダイオードを付け、ダイオードの線（カソード）が **ROW 側** を向きます。

| 信号 | ピン | 備考 |
| --- | --- | --- |
| ROW0 | D4 | 1段目 |
| ROW1 | D5 | 2段目 |
| ROW2 | D6 | 3段目 |
| ROW3 | D7 | 親指段 |
| COL0 | D21 | 左手の一番外側（右手では一番内側が D14） |
| COL1 | D20 | |
| COL2 | D19 | |
| COL3 | D18 | |
| COL4 | D15 | |
| COL5 | D14 | 左手の一番内側 |

右手側は列の並びが左右反転しています（内側から D14, D15, D18, D19, D20, D21）。
**左右の基板を同じ設計の裏返し（リバーシブル基板）にすると、自然にこの並びになります。**

親指段（ROW3）は内側の3列（COL3〜COL5 に相当する位置）だけ使います。

### トラックボールセンサー PMW3610（右手側のみ）

| センサー側 | ProMicro 側 | 備考 |
| --- | --- | --- |
| VDD / VIN | VCC (3.3V) | ブレイクアウト基板の表記に合わせる |
| GND | GND | |
| SCLK | D8 | |
| SDIO | D9 | データの送受信を1本で行う |
| NCS (CS) | D2 | |
| MOTION | D3 | 動いた時に知らせる割り込み線 |

### 電源まわり（左右共通）

- 電池の ＋ → 電源スイッチ → ProMicro の **B+ (RAW)**
- 電池の − → ProMicro の **B- (GND)**
- 電源スイッチは必ず付けましょう（持ち運び中の電池消耗防止）
- **リセットスイッチ**（RST と GND の間）も付けると書き込みが楽です

### 電池（リチウムポリマー）の選び方

- **保護回路付き（PCM付き）を必ず選ぶ**
- 型番の数字はサイズ：`502030` = 厚さ5.0mm × 幅20mm × 長さ30mm
- 容量の目安
  - 右手（セントラル＋トラックボールで消費が多い）：400〜500mAh（例：`503035` 前後）
  - 左手：200〜300mAh（例：`402030` 前後）
- JST-PH 2.0mm コネクタは**メーカーによって＋と−が逆**のことがある。
  基板に＋/−を印刷し、接続前にテスターで確認する
- 充電は ProMicro nRF52840 互換ボードに USB をつなげば自動で行われる

> ⚠️ ProMicro 互換品の中には、ピン配置が nice!nano と違う物もあります。
> 購入前に「nice!nano v2 互換」と書かれているか確認してください。

## 4. ファイルの構成と役割

```
zisaku/
├── .github/workflows/build.yml       … GitHub が自動でビルドするための設定
├── build.yaml                        … 何をビルドするか（左・右・リセット）
├── zephyr/module.yml                 … boards/ フォルダを読み込ませるための設定
├── config/
│   ├── west.yml                      … ZMK本体とトラックボールドライバの取得元
│   ├── kataware.keymap               … ★キー配置（一番よく編集するファイル）
│   └── kataware.conf                 … ★スリープ時間などの設定
└── boards/shields/kataware/          … キーボードの「ハードウェア定義」
    ├── Kconfig.shield                … シールド名の登録
    ├── Kconfig.defconfig             … 右がセントラル、分割、トラックボール有効 など
    ├── kataware.dtsi                 … 左右共通：マトリックス、行ピン
    ├── kataware_left.overlay         … 左手：列ピン
    ├── kataware_right.overlay        … 右手：列ピン＋トラックボール
    ├── kataware-layout.dtsi          … キーの見た目上の位置
    └── kataware.zmk.yml              … キーボードの説明情報
```

普段さわるのは **★の2つ** だけです。
`boards/` 以下は基板の配線を変えたときだけ編集します。

## 5. ファームウェアの作り方（GitHub Actions）

1. このリポジトリのファイルを編集して push する
2. GitHub のリポジトリ画面で **Actions** タブを開く
3. 数分待ってビルドが ✅ になったら、そのビルドを開いて下の方の
   **Artifacts** から `firmware` をダウンロード
4. zip を解凍すると次の3つが入っています
   - `kataware_left-nice_nano__zmk-zmk.uf2` … 左手用
   - `kataware_right-nice_nano__zmk-zmk.uf2` … 右手用
   - `settings_reset-nice_nano__zmk-zmk.uf2` … 設定リセット用

（ファイル名はバージョンにより少し違うことがあります）

---

## 6. 書き込み方法

1. キーボードを USB で PC につなぐ
2. **リセットボタンを素早く2回押す** → PC に `NICENANO` などのドライブが現れる
3. 左手なら `kataware_left…uf2` をそのドライブにドラッグ＆ドロップ
4. 自動で再起動したら完了。右手も同じように書き込む
5. PC の Bluetooth 設定で **「kataware」** を探してペアリング

### 左右がつながらない時

1. 左右両方に `settings_reset…uf2` を書き込む
2. 左右両方に、もう一度それぞれのファームを書き込む
3. 左右両方のリセットボタンを**同時に**押す
4. PC 側の Bluetooth 登録も一度削除してから、再ペアリング

## 7. 初期キーマップ

| レイヤー | 入り方 | 内容 |
| --- | --- | --- |
| 0 Base | 通常 | QWERTY |
| 1 Lower | 左親指の真ん中を押している間 | 数字、矢印キー、英数/かな |
| 2 Raise | 右親指の真ん中を押している間 | 記号、F1〜F5、Bluetooth 切替 |
| 3 Mouse | **ボールを動かすと自動で ON**（約0.7秒で OFF） | J=左クリック、K=中クリック、L=右クリック |
| 4 Scroll | Mouse 中に `;` キーを押している間 | ボールでスクロール |

- Bluetooth は Raise レイヤーの 2段目左から「接続先0〜4」「接続先の削除」です。
  スマホ・PC など最大5台を切り替えられます。
- 英数/かなは Lower レイヤーの A, S の位置にあります（Mac は確実に動作、Windows は IME の設定次第）。

## 8. よくあるカスタマイズ

### キーの割り当てを変える
`config/kataware.keymap` の `&kp Q` などを書き換えます。
キーの名前一覧：https://zmk.dev/docs/keymaps/list-of-keycodes

### カーソルの速さを変える
`boards/shields/kataware/kataware_right.overlay` の `cpi = <600>;` を変更（200〜3200、200刻み）。
大きいほど速くなります。

### カーソルの向きがおかしい
同じファイルの `// swap-xy;` `// invert-x;` `// invert-y;` の `//` を外して調整します。
センサーをケースにどの向きで付けたかで変わるので、実物で試しながら決めます。

### スクロールの向きが逆
`config/kataware.keymap` の `scroller` の部分を次のように変えます。
```
input-processors = <&zip_xy_to_scroll_mapper &zip_scroll_transform INPUT_TRANSFORM_Y_INVERT &zip_scroll_scaler 1 8>;
```
（ファイル先頭に `#include <dt-bindings/zmk/input_transform.h>` も追加）

### キーボードの名前を変える
`kataware` という文字をすべて新しい名前に置き換え、ファイル名の `kataware` も同じように変えます。
Bluetooth に表示される名前は `Kconfig.defconfig` の `ZMK_KEYBOARD_NAME` です（16文字以内）。

### キーの数を増やす・減らす
次の3か所の数を揃える必要があります。
1. `kataware.dtsi` の `default_transform` の `map`（どのスイッチがどの位置か）
2. `kataware-layout.dtsi` の `keys`（見た目の位置）
3. `kataware.keymap` の各レイヤーの `bindings`（割り当て）

例えば右手の親指キーを1つ減らしてトラックボールを置く場合は、
3か所すべてから同じ1キーを消します。

## 9. 次にやること（ハードウェア）

1. **部品を決めて買う**：ProMicro nRF52840 互換 ×2、PMW3610 ブレイクアウト、25mm ボール、
   支持球、キースイッチ ×42、ダイオード（1N4148 など）×42、電池 ×2、電源スイッチ ×2、リセットスイッチ ×2
2. **キー配置を決める**：[Keyboard Layout Editor](http://www.keyboard-layout-editor.com/) や
   [Ergogen](https://ergogen.xyz/) で配置を決める（Ergogen は配置から基板の下書きまで作れます）
3. **基板設計**：[KiCad](https://www.kicad.org/) で回路図 → 基板。上の配線表どおりにつなぐ
4. **ケース・ボールケース設計**：トラックボールのセンサーとボールの距離（PMW3610 は約2.4mm）が重要
5. **組み立て後**、まずキーだけ → 次にトラックボール、と1つずつ動作確認
