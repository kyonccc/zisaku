# 構想「浮島（うきしま）」

ボールユニットだけが机から立つ「柱」になり、基板（＋薄いプレート）がそのまわりに浮いて見える構成。
「しなる」軽さ（dotmatrix の方向）と、ガスケットのそろった押し心地を合わせた案。
**イメージ確認用**で、まだ製作用のデータではない（`case/concept_ukishima.py`）。

## 変えないもの

XIAO nRF52840 Plus・nice!view・エンコーダー・46 キー・トラックボール（19 / 25 / 34mm）・無線の分割・Choc v2

## 構成

| 部分 | 内容 |
| --- | --- |
| トレイ | 低い枠（縁の高さ 7.5mm）と床。縁は**基板より低い**ので、横から見ると基板が浮いて見える |
| 支え方 | トレイから立てた**柱の上のポロン（ガスケット）**で、基板＋薄いプレートを上下から挟む。外周 6 か所＋内側 2 か所（キーの角どうしのすき間）。内側にも支えがあるので押し心地がそろう |
| 基板＋プレート | いっしょに浮く。プレートは薄め（スイッチが抜けにくく、しなり方もそろう） |
| ボールユニット | 机から立つ柱。トレイの床に落とし込んで低くした。基板・プレートには触れない |
| カバー | 縁のかぶり 0.5mm・傾き 20°（前より約 4mm 低い）。ひねってロック |

## 高さ（机から・25mm ボール）

## これから決めること

- 柱の位置と数（試作で押し心地を確かめて調整）
- 基板とプレートの色（縁がそのまま見えるので、デザインの要になる）
- トレイの素材・色（3D プリント／着せ替え）
- 34mm ボールの柱（ユニット外径 約 38mm）の見せ方
