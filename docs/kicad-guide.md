# KiCad で kataware の基板を仕上げる手順（初心者向け）

Ergogen で作った基板の下書き（`pcb/ergogen/output/pcbs/left.kicad_pcb` / `right.kicad_pcb`）を
KiCad で開いて、部品の置き換え → 配線 → 検査 → 発注データ作成 まで進めます。

**1ステップ終わるごとに、画面のスクリーンショットか、困ったことを送ってください。**
一緒に確認しながら進めます。

---

## ステップ0：準備

1. **KiCad をインストール**
   - 公式サイト https://www.kicad.org/download/ から、使っているパソコン（Windows / Mac）用の**最新版**をダウンロードしてインストール
   - インストール時の設定は、基本的にすべて初期設定のままでOK
2. **kataware のファイルを手元に用意**
   - https://github.com/kyonccc/zisaku を開き、緑の **Code** ボタン → **Download ZIP**
   - ダウンロードした ZIP を解凍する

> Ergogen は「回路図」を作らず、「基板」だけを作ります。キーボードの自作ではよくあるやり方で、
> 今回は **PCB エディター（基板エディター）だけ**で作業します。

---

## ステップ1：基板ファイルを開いて眺める

1. KiCad を起動し、**PCB エディター**（基板の絵のアイコン）をクリック
2. メニューの **ファイル → 開く** で、解凍したフォルダの
   `pcb/ergogen/output/pcbs/left.kicad_pcb` を開く
   - 古い形式の変換について聞かれたら「はい」でOK
   - **エラーが出て開けない時は、その文章をそのまま送ってください**
3. 開けたら、次の3つを確認
   - 外形（角の丸い長方形）が見える
   - キーの位置に部品（スイッチとダイオード）が並んでいる
   - 部品どうしを結ぶ**細い線（ラッツネスト）**がたくさん出ている
     → これは「まだ配線していない、つなぐべき所」を示す線です
4. **表示 → 3D ビューアー**（ショートカット `Alt + 3`）で立体表示してみる

### 画面の見方（最低限）

| 層の名前 | 意味 |
| --- | --- |
| F.Cu | 表側の銅（配線） |
| B.Cu | 裏側の銅（配線） |
| Edge.Cuts | 基板の外形（ここで切り抜かれる） |
| F.Silkscreen / B.Silkscreen | 表・裏に印刷される文字や線 |

右側の「外観」パネルで、層ごとに表示/非表示を切り替えられます。

---

## ステップ2：部品の確認（置き換えは済んでいます）

XIAO・電源スイッチ・センサー用コネクタ J・電池コネクタは、**最初から本物の部品データ**が入っています
（以前の「仮の部品」を置き換える作業は不要になりました）。開いたら、次を目で確認するだけで OK です。

| 部品 | 確認すること |
| --- | --- |
| XIAO（MCU1、基板の裏） | 横向きで、USB-C 側が内側の側面（基板の「舌」の先）に来ている |
| 電源スイッチ（PWR1） | ピンクの枠の出っ張り（レバー）が基板の外にはみ出している |
| センサー用コネクタ（J1、右手の裏） | Enter と N のあいだにある |
| 電池コネクタ（BAT1、基板の裏） | 差し込み口が電池の置き場所の方を向いている（浮島：左手は電池の右隣、右手は電池の左上） |
| M2 ナット（H1〜H8、基板の裏・白い丸） | キーの角どうしのすき間に 8 か所。トレイの柱と同じ位置（動かさない。動かす時は `config.yaml` とトレイを両方直す） |

> 3D ビューアー（`Alt + 3`）で部品が表示されない物があっても問題ありません（XIAO は 3D の形が入っていません）。

> 基板は「浮島」用（トレイの柱の上のポロンに乗せ、裏の M2 ナットで下から留める。内側の側面に USB-C と電源スイッチ用の「舌」がある）。
> ナットのパッドは φ5.0・穴 φ2.4（めっき）。**買うナットのデータシートに合わせて、パッドの大きさだけ KiCad で調整してよい**。
> 外形を変えたい時は KiCad ではなく `pcb/ergogen/config.yaml` を直して作り直す（ケースの 3D データも同じ外形を使うため）。

> ⚠️ 販売する予定なので、追加する部品データは **KiCad 標準ライブラリ**か、
> 販売してよいライセンスのものだけを使う（「NC（非営利）」と書かれたものは使わない）。

---

## ステップ3：設計ルールを決める（JLCPCB に発注する前提）

**ファイル → 基板の設定 → 設計ルール** で、次のように設定します。

| 項目 | 値 | 意味 |
| --- | --- | --- |
| 最小クリアランス | 0.2mm | 線と線のすき間 |
| 信号線の太さ | 0.25mm | キー・センサー・画面の線 |
| 電源線の太さ | 0.5mm | 電池・電源スイッチ・3V3・GND |
| ビア | 直径 0.6mm / 穴 0.3mm | 表と裏をつなぐ小さな穴 |

---

## ステップ4：配線する

| 操作 | ショートカット |
| --- | --- |
| 配線を引く | `X` |
| 配線中に表⇔裏を切り替える（ビアが入る） | `V` |
| 選んだ物を消す | `Delete` |
| 元に戻す | `Ctrl + Z`（Mac は `⌘ + Z`） |

### 配線の方針（迷わないためのルール）

- **行（ROW0〜3）は表（F.Cu）で横に、列（COL）は裏（B.Cu）で縦に**引く
  → 縦と横が別の面なので、ぶつかりにくい
- 電源（電池 → スイッチ → XIAO の BAT+）は太い線（0.5mm）で短く
- 全部の細い線（ラッツネスト）が消えたら配線完了

最初は**1列だけ**引いてみて、スクリーンショットを送ってください。やり方が合っているか確認します。

---

## ステップ5：検査（DRC）

**検査 → デザインルールチェッカー** を実行して、**エラーが 0** になるまで直します。
エラーの意味が分からない時は、表示された文章を送ってください。

---

## ステップ6：発注データを作る

JLCPCB などに送る「ガーバーデータ」を作ります。手順はステップ5が終わった時にまとめて説明します。

---

## 困った時は

- 画面のスクリーンショット
- 何をしようとして、どうなったか

を送ってもらえれば、それに合わせて説明します。
