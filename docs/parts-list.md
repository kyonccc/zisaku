# kataware（浮島）部品リスト

キーボード 1 台（左右 1 組）を作るのに必要な物の一覧です。
**「設計の値」は今のデータが前提にしている寸法**です。実物（または販売ページ・データシート）の値を「実測」に書き、
違っていたら右端の数字（`case/concept_ukishima.py` などの名前）を直して作り直します。

- 数は左右の合計。「左／右」で分かれる物は（左 ○・右 ○）と書いた
- **高さ**は、基板の面から出る量（表は上へ・裏は下へ）
- ★ … 高さ・大きさがケースの形に効く物（実測してほしい物）

## 模型（モック）で大きさと高さを確かめる

部品を買う前に、**大きさと高さだけ**の模型を印刷して手を置いてみる。データは `case/stl/mock/`（作り直しは `python3 case/mock.py`）。

![模型](images/mock.png)
![模型（横から）](images/mock-side.png)

| STL | 中身 | 印刷 |
| --- | --- | --- |
| `mock_tray_left` / `_right` | 本物と同じトレイ（柱だけポロンの分まで高い） | 床を下 |
| `mock_top_left` / `_right` | 基板＋プレート＋スイッチ＋キーキャップ＋nice!view（カバー込み）＋エンコーダー（左）のかたまり | 下の平らな面を下（キーキャップのふちに少しだけ張り出し） |
| `mock_ball_19` / `_25` / `_34` | ボールユニットとボールの外形 | 底を下 |

- **早く・安く**印刷する設定でよい（積層 0.28mm・インフィル 10%・壁 2 周）。形を見るだけなので、色も 1 色で OK
- 組み方：トレイに上の模型を乗せる（柱の上に乗る）。右手はボールの模型をトレイの穴に入れる
- 確かめること：手を置いた時の高さ・キーの位置とボールの距離・持ち運ぶ時の大きさ・エンコーダーのつまみの高さ
- **部品を実測して数字を直したら、もう一度 `python3 case/mock.py` を実行**すると、模型の高さも変わる
