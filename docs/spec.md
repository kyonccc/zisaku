# kataware 仕様（振り出し版）

これまでの検討をいったんリセットし、ここを唯一の基準とする。
ここに書いていないことは「未決定」。

## 確定

| 項目 | 内容 |
|---|---|
| 接続 | 無線（ZMK / XIAO nRF52840 / リポ電池） |
| 形 | 分割、外形は左右対称 |
| キー数 | 片側 3段6列＋親指3 ＝ 計42キー |
| スイッチ | Choc V2（ホットスワップ）、ロープロファイル |
| トラックボール | 右手側のみ。19 / 25 / 34mm に対応 |
| センサー | PMW3610 |
| 高さの基準 | ボールまわりは 34mm 基準で設計（どのサイズでも同じケースを使う） |
| 持ち運び | 可能にする |
| 裏面 | ゴム足、マグネット |
| マグネットの用途 | 左右をくっつけて1つにまとめて運ぶ |

## 解釈（違っていたら直す）

- 「本体ごと34mm基準」＝ トラボの下ケースは34mmが入る大きさで共通にし、
  サイズ違いは上の球押え（爪）の交換だけで対応する。
- キーの部分はロープロファイルのまま薄く保ち、高くなるのはトラボまわりだけ。
- 左手側にはトラボがないが、外形と裏面（足・磁石の位置）は右と鏡写しにそろえる。
