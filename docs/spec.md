## 確定

| 項目 | 内容 |
|---|---|
| 接続 | 無線（ZMK / XIAO nRF52840） |
| 形 | 分割、外形は左右対称 |
| 配列 | オーソリニア。配置は当初の試作と同じ（ボールは右手の内側手前の角、XIAO はその奥） |
| キー数 | 片側22キー（計44）か21キー（計42）で検討中 |
| スイッチ | Choc V2（ホットスワップ）、ロープロファイル |
| トラックボール | 右手側のみ。センサーは PMW3610 |
| ボールまわり | 角の土台は 34mm 基準でトレイと一体。PMW3610 は土台に固定し、外さない。上の筒（カップ・爪）だけを 19 / 25 / 34mm で交換する（images/concept-cup-swap.png） |
| 筒の留め方 | トレイの裏から M2 ビス3本。筒の柱にインサートを入れる（images/concept-cup-screws.png） |
| ボールの位置 | センサーとボールの距離が同じになるよう、大きさごとに中心がずれる（小さいほど角寄り・低い） |
| 左手の角 | 右と同じ外形の土台にホイール（エンコーダー）。手前と奥に転がす。直径18・幅7mm を想定、上に約4.5mm 出す（images/concept-left-wheel.png） |
| 操作する指 | 19 / 25mm は親指。34mm は親指に加え人差し指・中指も想定 |
| 高さ | ボールの頭とキーの高さのバランスを取る |
| 厚み | 市販の薄型トラボ付き分割キーボードと同程度 |
| 持ち運び | 左右を背中合わせにして運ぶ |
| 裏面 | ゴム足、マグネット（背中合わせ用） |
| マイコン | XIAO nRF52840 を上面（キーの奥・内側）に見える形で載せる。USB-C は奥向き（images/concept-mcu-top.png） |
| 電源 | スライドスイッチで ON/OFF。XIAO のすぐ手前の上面に置く |
| 画面 | なし |
| 大きさ | 片側 約141×85mm。角はトラボの土台がそのまま外形になる。キーのまわりの縁は4mm（images/concept-tray-small.png） |
| ケース構造 | 薄さが確保できればガスケット（浮島）構造を続ける |

## 検討中

### キーピッチ: 17mm か 19mm
- 19mm: キーキャップの選択肢が多い。手の大きい人も使いやすい。
- 17mm: 本体が小さくなり持ち運び向き。使えるキーキャップが限られる。

### ボールの高さ（机から。キーの上面は 22.75mm）
| ボール | 頭 | キーとの差 | 中心 | 34mm からの横ずれ |
|---|---|---|---|---|
| 34mm | 36.5mm | +13.8mm | 19.5mm | 0 |
| 25mm | 29.8mm | +7.0mm | 17.3mm | 3.9mm 角寄り |
| 19mm | 25.3mm | +2.5mm | 15.8mm | 6.5mm 角寄り |

### キー数
- この配置だと片側22キー（計44キー）。42キーにするなら片側1つ減らす。
- 候補図: images/layout-d-candidates.png（上がオーソリニア）

### 電池（使う部品が変わる）
- リポ電池: 背面ケースに入れる。XIAO で充電できる。
- 乾電池: 上面から入れる。昇圧回路が必要、充電はできない。
